**Brand name:** Servelink  
**Tagline:** Your Local Service. One Platform.  
**Purpose:** Connect customers with nearby service professionals and help customers find the right expert through AI-assisted problem understanding, photo uploads, smart search, and professional recommendations.

This is a college startup competition project. Build a polished, interactive MVP that looks like a real commercial product.

IMPORTANT: If an existing Servelink project is available, inspect and update it without deleting working features. If this is a new project, build the website from scratch. Do not create a separate project unnecessarily.

## 4. AI Service Assistant

Build an AI Service Assistant that helps customers identify the right type of professional.

The assistant should contain:
- Text box for describing a problem.
- Optional photo upload.
- Location selector.
- Optional budget.
- Optional urgency or preferred date.
- "Find Best Professional" button.
- Loading indicator.
- Problem summary.
- Suggested service category.
- Matching professionals.
- Explanation of why each professional is recommended.
- Call and Book Now actions.

Heading:
"Tell us what's wrong. We'll help you find the right expert."

Placeholder:
"Describe your problem, e.g. My AC is running but not cooling the room..."

### Example: AC cooling problem

Customer writes:
"My AC is running, but it is not cooling the room."

The assistant should:
- Suggest AC Repair.
- Summarize the problem as an AC cooling issue.
- Recommend nearby AC technicians.
- Prioritize relevant cooling-system experience.
- Match the brands the customer selects.
- Explain why each professional is recommended.

Do not claim to know the exact cause without an inspection.

### Example: Washing machine problem

Customer writes:
"My washing machine makes noise and does not spin."

Recommend suitable washing machine repair professionals.

### Example: Electrical problem

Customer writes:
"My electrical socket is not working."

Recommend an electrician. For potentially dangerous electrical issues, advise the customer not to touch exposed wiring and to seek qualified assistance.

### Photo-based problem reporting

Customers must be able to upload a photo of a damaged appliance, vehicle, or other item.

- Photo upload is optional.
- Text-only problem descriptions must work.
- Display a preview of the uploaded image.
- Allow customers to remove or replace the image.
- Validate image type and file size.
- Use vision-capable AI when correctly configured.
- If AI is unavailable, provide a rule-based demo fallback.

Never claim that a photo was analyzed by AI when it was not.

### AI integration

Use a server-side AI integration if an API key is configured in Replit Secrets as `OPENAI_API_KEY`.

Use a suitable vision-capable model supported by the configured API account.

Never expose API keys in frontend code or browser storage.

If no API key exists, implement useful keyword-based demo matching for common problems. Clearly label demo results and explain that genuine AI analysis requires configuration.

The website must remain usable without an API key.

3. Ask for the problem description.
4. Allow an optional problem photo.
5. Ask for the service address.
6. Allow date and available time selection.
7. Display the starting price and estimated cost information.
8. Allow the customer to submit the booking request.
9. Display a booking confirmation screen.

- Confirmed.
- Completed.
- Cancelled.
